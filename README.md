# Master Study Maps

Interactive study maps and flowcharts for medical school block review.

- [Open Gastrointestinal](https://midnight-canvas0608.github.io/neurology-study-map/gastrointestinal.html) — 613 study cards and 156 flowcharts, with clinical pathways, concept links, active recall, and coverage from First Aid plus 52 class lecture and BNB resources.
- [Open Psychiatry](https://midnight-canvas0608.github.io/neurology-study-map/psychiatry.html) — 257 study cards, 55 flowcharts, active recall, and a Pharmacology section. Includes sleep, seizures, delirium, and dementias.
- [Open Neurology](https://midnight-canvas0608.github.io/neurology-study-map/)

Open any link directly in a browser. No GitHub account is needed to study. Confidence ratings and saved cards stay in each student's browser.

The Psychiatry page is a single file and can also be downloaded for offline use. Its original study summaries link to source references; the source textbook PDFs are not included.

The Gastrointestinal map is also a standalone HTML file. Course-source references identify the relevant resource and pages; original textbook PDFs and lecture slides are not included.
